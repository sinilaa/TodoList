# Todo List

## Description

This is a simple React Native Todo List application. Users can add tasks, mark them as completed by pressing them, and view their tasks in a list.

The tasks are saved to the phone's local storage, so they remain available when the application is reopened.

## Features

- Add new tasks
- Mark tasks as completed or uncompleted by pressing them
- Completed tasks are displayed with strikethrough text
- Save tasks using AsyncStorage
- Display tasks in a list

## Technologies used

- React Native
- Expo
- TypeScript
- AsyncStorage

## Running the application

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npx expo start
   ```

5. Scan the QR code with Expo Go to open the application on your phone.
